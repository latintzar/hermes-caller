# Hermes Caller

Read the repository README and docs before assisting. Guide the operator through private HTTPS server configuration and Android setup. Keep keys in private configuration, never ask the operator to paste secrets into chat, and never place a call or activate recording without an explicit instruction. Use the offline tests for verification. Distinguish a successful local test from a live provider call.
